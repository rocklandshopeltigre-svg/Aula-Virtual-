Navegadores web

¿Qué es? Un navegador es el programa que nos permite abrir y ver páginas web. Recibe el código de la página (HTML, CSS y JavaScript) y lo convierte en lo que vemos en pantalla.

¿Qué hace cuando escribes una dirección?

  1. Escribes la dirección (URL) en la barra.
  2. El navegador pide la página al servidor donde está alojada.
  3. El servidor responde con los archivos HTML, CSS y JavaScript.
  4. El navegador los interpreta y muestra la página.

Buscadores

¿Qué es? Un buscador es un sitio web que organiza el contenido de internet y, cuando escribes una consulta, te muestra los resultados más relacionados. No es lo mismo que un navegador: el navegador abre la página del buscador.

¿Cómo funciona?

  1. Rastrea: programas llamados arañas recorren las páginas web.
  2. Indexa: guarda y ordena lo que encontró en un gran índice.
  3. Responde: al buscar, compara tu consulta con el índice.
  4. Ordena: muestra primero los resultados más relevantes.
